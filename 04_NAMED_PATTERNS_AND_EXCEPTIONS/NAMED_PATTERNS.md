# Named Patterns

格局名称不是结论。每个 Named Pattern 必须经过：A 排盘门、B 组合门、C 激活门、D 现实门。仅 A 成立时只记录结构；A+B 可说明方向；A+B+C 是阶段观察；A-D 全部成立才可写条件性现实场景。

## 禄马交驰类

- **Trigger**：禄与天马或迁移/财帛/官禄同题关联，并有外部平台线支持。
- **Meaning**：资源随行动、外部场景或跨平台展开的候选。
- **Scope**：已有异地岗位、客户拓展、出差、跨平台项目或外部市场。
- **Boundary**：不等于离乡必富、出国或收入增长。
- **Exception/Conflict**：无现实项目时仅为对流动资源敏感；忌煞或现金流不足可表现为差旅成本、承接压力。

## 昌曲/科名类

- **Trigger**：昌曲、化科与命官财迁某轴形成至少两条独立同题支持。
- **Meaning**：通过知识、表达、作品、记录、审核与专业反馈获得可见度的候选。
- **Scope**：考试、证照、作品、研究、报告、教学、公开展示或专业履历竞争。
- **Boundary**：不等于学历、名声、收入或成功。
- **Exception/Conflict**：没有输出场景时只表现为学习、整理和表达偏好；文书/验收链有阻力时可伴随反复修改。

## 煞破/变动类

- **Trigger**：破军、七杀、羊陀火铃、化忌等与主题宫形成实质组合且阶段被激活。
- **Meaning**：变动、重组、决策速度、责任与摩擦上升的候选。
- **Scope**：转岗、创业、项目重组、关系谈判、资产处置等既有载体。
- **Boundary**：不等于意外、官非、破产或终局失败。
- **Exception/Conflict**：无载体时只写决策风格、对旧模式的不耐受或准备期。

火贪、铃贪及其他传统命名格局的可靠通用 Trigger/Meaning/Boundary：旧已消化资产不足，`UNRESOLVED`，不得依据名称自行补全。
