# Soft Signal Library

Status: `REPRESENTATIVE_EXAMPLES`

`SOFT_SIGNAL_LIBRARY != COMPLETE_LIST`.

The following IDs are representative examples. Their names are retrieval labels, not new single-star rules. A Strong Reasoner may create a new Soft Signal when it is traceable to legal evidence, respects every Core boundary, does not use mechanical topology, does not duplicate an evidence identity, and uses a strength allowed by `SOFT_SIGNAL_LAYER.md`. A new ID does not become a permanent astrological rule merely because one analysis used it.
