# Soft Signal Layer

Status: `OPTIONAL_POST_CORE_LAYER`

`SOFT_SIGNAL_LAYER` runs only after the Hard/Core conclusions are complete and frozen. It provides a small number of auxiliary tendencies when the structure is useful but insufficient for a formal Core claim.

It is not a Core Rule, score, vote system, accuracy-expansion device, or fallback for failed claims. It cannot modify, override, upgrade, or reverse:

- `NATAL_RESOURCE_BASELINE`
- `CAREER_WEALTH_SYSTEM`
- `MARRIAGE_SYSTEM`
- `DECADE_RESOURCE_BAND`
- `DECADE_DELTA`

## Strength

- `CLEAR_TENDENCY` (display: 特征比较明显): at least two non-duplicate, same-direction evidence paths and no clear structural conflict. May enter the report body.
- `HAS_SIGNAL` (display: 有一点这个象 / 可以留意): one main path plus one auxiliary direction, or one highly discriminative structure that is insufficient for Core. Non-inevitability language is mandatory.
- `AUXILIARY_ONLY` (display: 仅辅助提示): one auxiliary signal. Suppressed by default; mention only when the user explicitly asks the domain.

No numeric strength or score is allowed.

## Output limit

A complete Natal report may proactively show `3–5` Soft Signals. More than five is a failure. Prefer signals that complement Core, explain observable reality, and increase chart discrimination. Do not fill the quota.

## Required execution order

```text
Core output frozen
→ candidate retrieval from representative library and/or traceable synthesis
→ source-identity deduplication
→ conflict/suppression check
→ strength gate
→ 3–5 item output limit
→ check that each signal remains specific to its supporting structure
```

`SOFT_SIGNAL_LIBRARY != COMPLETE_LIST`. A new signal may be synthesized only when it satisfies the same schema, strength gate, Core priority, source-identity deduplication and mechanical-topology prohibition.
