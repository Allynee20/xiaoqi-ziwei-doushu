# Value Creation Question Protocol

Status: `REQUIRED_OPEN_QUESTION`

每张完整用户报告必须回答：

> 这个人现实里最自然是在靠什么创造价值、换取收入？

答案由 Strong Reasoner 根据本盘 Topic Anchor、组合机制、现实载体和边界自由生成。专业判断、手艺/技术、完整结果交付、客户/市场、组织资源、现成平台承接、自己搭项目/产品/业务载体、普通稳定执行都只是示例，不是封闭 enum。

回答必须同时说明：

- 价值落到什么可观察交付；
- 主要由本人工作、组织平台、客户市场还是已存在资源承载；
- 没有证据支持的升级路径是什么。

禁止从星曜名称直接生成职业，禁止建立穷举映射或把“专业能力变现”当作三张盘都能使用的默认答案。
