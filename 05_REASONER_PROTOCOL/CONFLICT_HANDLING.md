# Conflict Handling

## 分类

| 类型 | 识别 | 处理 |
|---|---|---|
| 不同问题 | 两个信号回答不同 Topic/维度 | 并列保留，不称冲突 |
| 支持与成本并存 | 同一行动既有资源也有责任/阻力 | 写出交换条件，不相抵 |
| 修饰 | 辅煞、状态或关系改变表达方式 | 回到主结构说明“如何改变” |
| 证据依赖 | 多条表述来自同一物理路线 | 合并为一组，不重复计票 |
| 真冲突 | 同一对象、范围、维度、语义槽中出现不相容证据，旧知识无授权解法 | 标 `CONFLICTED`，保留双方与影响 |
| 来源争议 | 历史材料口径不同但尚未成为盘面证据冲突 | 标 `UNRESOLVED` 或 knowledge source conflict，不伪装成结论 |
| 缺失/未知 | 所需字段不存在或覆盖不完整 | 标 `INSUFFICIENT/UNRESOLVED`，不是负面 |

Reasoner 不得用多数票消灭少数证据，也不得因需要“最终答案”而自行裁决旧项目未解决的争议。
