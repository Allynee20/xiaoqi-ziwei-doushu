# Reasoning Sequence

前置定位：先读 `REFERENCE_TARGET_POLICY.md` 与 `USER_REPORTS/DEFAULT_ANALYSIS_SCOPE.md`。Public v1 默认产品范围是 `PERSON / WORK_VALUE_CREATION / RELATIONSHIP` 的本命结构分析；Decade、Lifecycle、Future Stage、Annual 与 Dynamic Facts 在默认路径一律 `OFF`。V4 冻结语法与边界，不穷举每个结果；Strong Reasoner 保留综合职责。重要结论区分 `REFERENCE_KNOWLEDGE / PROJECT_SCHEMA / EXTERNAL_RESEARCH / MODEL_INFERENCE`。

1. 用用户问题决定当前 Topic，按 `../reference/07_TOPIC_METHOD_ROUTER/TOPIC_ANCHOR_METHOD.md` 建立 `TOPIC_ANCHOR / SUPPORTING_STRUCTURES`，不把十二宫同权展开；Anchor 不得成为 sole evidence。
2. 锚定本人、伴侣、父母、子女、单位、平台、团队与外部环境等对象。
3. 检查盘面事实是否完整、是否来自同一算法版本。
4. 先执行 `LIFE_DOMAINS/MECHANICAL_TOPOLOGY_GUARD.md`：机械宫位落点只导航检索，不进入个性化证据。
5. 按 `../reference/05_COMPOSITION_AND_RELATIONS/COMPOSITION_AND_PATTERN_METHOD.md`：多星稳定共同结构先执行 `COMPOSITE_FIRST`，形成共同机制后再进入 Palace、Transform、Local Modifier、Sanfang/Opposite/Borrow 与 Topic；禁止拼接单星文本。
6. 按 `MODIFIER_ORDER_AND_PRECEDENCE.md` 组合；Named Pattern 用 `REQUIRED / REINFORCING / BREAKING` 和 `COMPLETE / PARTIAL / BROKEN / INACTIVE` 检查，不作枚举或计分。
7. 识别同一 evidence identity 的多视图，避免重复计数。
8. 区分主证、支持、背景、条件、成本、修饰与真冲突。
9. 默认只综合本命 Person、Work/Value Creation 与 Relationship。本人收入或资金机制只有在有独立正面信息时才纳入 Work 模块；不得自动运行完整 Wealth、Decade、Annual 或 Lifecycle 分析。既有 Baseline / Decade 方法保留于内部能力，不因 Public v1 的默认关闭而删除。
10. 默认不生成大运、流年、未来阶段或机械运序叙事；相关分析只有在另行明确启用独立范围后才适用既有内部方法，不属于本 Public v1 默认报告。
11. 按 Subquestion 比较不同维度，但不把不同维度做净分。
12. 按 `../reference/06_SYNTHESIS_METHOD/CLAIM_CARD_METHOD.md`：对每个核心判断先建内部 Claim Card：`CLAIM / WHY / BOUNDARY / OPTIONAL_SOFT_SIGNAL`；WHY 保留 2–4 条独立证据链，最终改写为自然语言而不打印字段名。
13. 按 `ANTI_BARNUM_AND_DISCRIMINATION.md` 把每条重要结论写成 `EVIDENCE / REAL_WORLD_DIMENSION / CONTRAST / CANNOT_IMPLY / MISS_CONDITION`。
14. 执行 Lifecycle Template、Universal Phrase、Domain Reassignment 与 Sentence Swap Test；可交换主结论标为 `NON_DISCRIMINATIVE`，重写或删除。
15. 冻结 Hard/Core 输出；随后才可运行 `SOFT_SIGNALS/SOFT_SIGNAL_LAYER.md`，软象不得回写或升级 Core。
16. Soft Signal 按 source identity 去重、检查 Core conflict 与 domain，主动输出限 3–5 条；机械拓扑不得成为软象。
    `SOFT_SIGNAL_LIBRARY != COMPLETE_LIST`；新软象只有在可溯源、守 Core 边界、不重复 evidence、强度匹配时才可创建。
17. 综合并冻结内部结论，检查其中没有未经支持的扩展或跨域推断。
18. 输出普通用户版前，执行 `USER_REPORTS/FINAL_USER_REPORT_PROTOCOL.md` 的 positive-evidence-only rendering：按 Person、Work / Value Creation、Relationship 三个模块组织；可选总结只能压缩前三者。保留内部状态，静默省略未知、未解决、缺少支持及范围外主题；清除审计 / 研究措辞、范围免责声明与排除式证明句，再冻结用户版。

## 禁止

- 见一颗星直接下结论；
- 见一个化忌就全盘判坏；
- 吉星加分、凶星扣分、数量投票；
- 把不同问题下的信号互相抵消；
- 为了强行给答案而忽略冲突；
- 把无证据、未知、未建模当负面；
- 用 V3 工程状态词替代最终用户可理解的分析。
- 从星曜直接跳到职业标签；
- 把派生宫写成外部人物的实际职业、收入或事实；
- 在首次推理前读取现实经历，或在揭示现实后扩写冻结结论。
- 把顺逆行、运序或固定宫位落点当成个性化 evidence；
- 用年龄模板自动生成“某十年起量、下一十年发财、再下一十年守财”；
- 用职位名称决定 Control Level，或用创业/公司经历自动判定成熟 Business Ownership；
- 将揭盲后的其他领域事实重新分配为原预测命中。
- 用 Soft Signal 覆盖、修改或升级 Natal Baseline、Career–Wealth、Marriage、Decade Band/Delta；
- 将同一物理证据的多个视图重复计为多个软象路径，或主动输出超过五条软象。
- 因 Reference 没有预编码某个组合就强行停止全部推理，或为补齐穷举覆盖而发明规则；
- 不得把 Examples、Pattern Library 或 Soft Signal Library 当成穷举式查表预测器。
