# Analysis Protocol

Before analysis, apply `USER_REPORTS/DEFAULT_ANALYSIS_SCOPE.md`: the Public v1 default is Natal-only `PERSON / WORK_VALUE_CREATION / RELATIONSHIP`. Dynamic, decade, annual, and lifecycle branches remain OFF unless an independent analysis scope is explicitly enabled outside the default public path.

```text
Question
↓
确定 Topic / Subquestion / 对象 / 时间范围
↓
Context Mapping：选择主线宫位、角色与辅助接口
↓
Topic Anchor：区分 TOPIC_ANCHOR / SUPPORTING_STRUCTURES
↓
读取 structured natal facts；先处理缺失与冲突
↓
Primitive Meaning：星、宫、四化、状态、关系
↓
Composition Grammar：本宫主结构、修饰、关系视图
↓
Composite First：共同机制先于单星文本拼接
↓
Named Pattern：Required / Reinforcing / Breaking / Completeness
↓
支持 / 修饰 / 成本 / 冲突 / 证据独立性分析
↓
主次判断；不同维度保持分离
↓
保留 PARTIAL / CONFLICTED / UNRESOLVED / INSUFFICIENT
↓
Anti-Barnum 五段式结论 + Universal Phrase 检查
↓
Sentence Swap Test；可交换主结论改写或删除
↓
Synthesis
↓
内部 Claim Card → 用户自然语言
↓
Positive-evidence-only user rendering：保留内部不确定状态；用户正文静默省略未知、缺证、未解决和范围外内容
↓
冻结首次 Final Analysis；后续现实补充信息不得追溯扩写或重分配原结论
```

默认只使用 Project KB，并显式记录 `profile_id` 与 `transform_table_id`。发现知识缺口时停止该项扩写，按 `KNOWLEDGE_GAP_PROTOCOL.md/.json` 输出机器可读事件；不要自行联网、跨 Profile 补强或用模型记忆补齐。
