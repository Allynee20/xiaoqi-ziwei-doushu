# Reference Target Policy

Status: `REQUIRED_DEFAULT_PROTOCOL`

V4 是给 fresh strong Reasoner 使用的公开 Knowledge Reference，不是 exhaustive deterministic fortune engine。

## Authority split

- Deterministic engine：Birth → chart → structured facts。
- Reference：基础语义、组合语法、Topic 方法、边界、Schema、Profile、例外、样例和未决项。
- Strong Reasoner：综合、证据主次、冲突、语境、软象、自然语言和不确定性。
- Optional Web：传统来源、学派差异、罕见术语和未决研究；不得事后合理化。

## Non-exhaustive rules

- `FREEZE GRAMMAR, NOT EVERY RESULT`。
- `COMPOSITE_FIRST` 不是穷举双星/多星组合。
- Pattern role/completeness 是 `PROJECT_SCHEMA` 推理辅助；Pattern library 不完整且不得变成枚举引擎。
- `SOFT_SIGNAL_LIBRARY != COMPLETE_LIST`；满足 Guard 和 Schema 时，Reasoner 可创建可溯源的新软象。
- Examples, patterns and signal libraries are illustrative and non-exhaustive; they are never lookup predictors.
- Generated combinatorial corpora are not lookup predictors and must not be embedded wholesale in the Reference.

## Unknowns

没有预编码组合时：

- 若已有 Primitive、Composition、Profile 与 Topic 边界足够，标记 `REASONER_SYNTHESIS_ALLOWED` 并给出溯源；
- 若关键语义、流派或事实不足，输出 `UNRESOLVED / KNOWLEDGE_GAP`；
- 不得为追求覆盖率发明紫微知识。

## Provenance labels

重要结论必须可区分 `REFERENCE_KNOWLEDGE / PROJECT_SCHEMA / EXTERNAL_RESEARCH / MODEL_INFERENCE`。Project Schema 名录见 `reference/06_SYNTHESIS_METHOD/PROJECT_SCHEMA_REGISTRY.md`。
