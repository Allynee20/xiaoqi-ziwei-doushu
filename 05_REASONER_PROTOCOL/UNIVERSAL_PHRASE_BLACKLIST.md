# Universal Phrase Blacklist

Status: `REQUIRED_DEFAULT_PROTOCOL`

This is a usage blacklist, not a token filter. A similar phrase is allowed only after it names an observable dimension, structural contrast, and miss condition.

| Generic phrase | Why it fails | Required discriminative replacement |
|---|---|---|
| 适合处理复杂问题 | Nearly any role can absorb “complex” | Name whether the evidence concerns rule reconciliation, rapid decisions, documentation/verification, resource allocation, or route reconstruction; state the opposite mode and falsifier. |
| 事业有发展 | No axis or observable outcome | Name role, platform, authority, deliverable, continuity, or route-change dimension; do not turn it into success. |
| 今年有变化 | Every year contains change | Name the layer, activated object, type of change, and what unchanged reality would count as a miss. |
| 有贵人 | Hides role and delivery path | Name institution, collaborator, client, reviewer, or qualification entrance and the required handoff; support is not result. |
| 比较有责任感 | Personality praise without scope | Name the object and task where responsibility appears, its cost, and the alternative pattern. |
| 关系需要沟通 | Universal relationship advice | Name negotiation object, pace, boundary, commitment step, or disagreement mechanism and the miss condition. |
| 有自己的想法 | Applies to almost everyone | Name decision locus, rule boundary, alternative generation, or resistance to external coordination. |
| 事业做大钱才会多 | Collapses career and wealth | Separate income formation, settlement, stability, retention, and source channels; specify which link is evidenced. |
| 外部会带来机会 | Confuses entry with acceptance/result | Name client/platform/mobility entry, acceptance and settlement as separate steps. |
| 这几年在调整自己 | Unbounded time and dimension | Name decade layer, activated palace/object, reconstruction target, and unchanged condition. |

## Absolute filler ban

The following are not acceptable analytical substitutes: `能量`, `人生课题`, `格局宏大`, `贵人加持`, `运势开启`.

## Enforcement

If a key claim can be paraphrased only with a blacklisted sentence, classify it `NON_DISCRIMINATIVE`. Rewrite it under the five-part claim contract or omit it.
