# Evidence and Trace Rules

- 每条关键解释应能回溯到：物理宫、星曜、四化（如有）、关系视图、来源层和 evidence identity。
- 一颗带四化的星是一个组合物理事实；Star×Palace、Transform×Palace 与 Star×Transform 是其成分/状态，不是多票。
- 同一 `sourceEvidenceId/evidenceGroupId` 的 LOCAL、SANHE、OPPOSITE、BORROWED_VIEW 是相关视图。
- `Borrow != relocation`；借宫保留物理来源，不制造新星、新四化或新证据。
- projection 不能凭空制造 evidence，也不能链式投影。
- `relation != path != outcome`；结构关系不能直接洗成主题路径或现实结果。
- 生年四化是星曜属性；宫干飞化是 DTR 有向边；机制层分开。
- 来源与推理链要可回溯；每条重要判断应能标明对应 Canonical 知识、Project Schema 或模型综合。
