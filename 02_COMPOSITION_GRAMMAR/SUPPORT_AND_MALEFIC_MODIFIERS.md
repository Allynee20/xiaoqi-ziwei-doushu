# Support and Malefic Modifiers

辅星、煞星、杂曜不独立替代主星与主题宫；它们通常承担以下一种或多种角色：

| 类型 | 作用 | 旧资产锚点 |
|---|---|---|
| 支持/补位 | 增加人力、协作、入口、资源或缓冲 | 左右、魁钺、禄存、德曜等 |
| 表达/验证 | 增加说明、文本、可见度、审核与专业呈现 | 昌曲、科 |
| 节奏/流动 | 改变速度、移动与资源展开场景 | 天马、火铃 |
| 摩擦/成本 | 增加急、卡、紧绷、冲突或非典型成本 | 羊陀、火铃、空劫 |
| 情绪质感 | 修改主结构的主观体验 | 哭虚、孤寡 |
| 修复出口 | 提供拆题、补救或善意缓冲 | 解神、德曜等 |

写作时必须说清：它修饰了哪个主结构、增加了什么资源或成本、在哪个对象接口出现。所谓“贵人”必须落到介绍人、决策者、导师、客户、预算或实际补位者；否则只能写“支持网络候选”。

煞星必须经宫位、完整结构、状态/强弱、时间层和现实载体过滤。单煞、单忌不生成事故、疾病、离婚、破产等结论。
