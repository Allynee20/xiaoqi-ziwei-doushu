# Modifier Order and Precedence

稳定阅读顺序，不是数学公式：

1. **问题与对象**：明确 Topic、Subquestion、主语、现实对象与时间范围。
2. **物理事实**：星曜、宫位、四化绑定、状态、命身和结构关系；先处理输入冲突。
3. **本宫主结构**：宫位对象 × 主星功能；双星先拆后合。
4. **四化**：确认来源层，再判断资源、推动、显化或阻力改变了原语义哪一维。
5. **状态/亮度**：Core 仅运输 raw state 与 provenance；默认 `BRIGHTNESS_SEMANTIC_CONSUMPTION = OFF`。只有显式 Profile 才能解释，且不能改写 identity。
6. **辅星/煞星/杂曜**：说明支持、资源、摩擦、成本、节奏或细节。
7. **关系结构**：按 LOCAL > 合法关系视图的次序加入对宫、三方、会照、夹宫与借宫；保留物理来源。
8. **Named Pattern / Exception**：仅在完整 Trigger 成立时启用。
9. **证据独立性**：按物理 identity 去重，区分支持、修饰、成本和真冲突。
10. **Context synthesis**：依据子问题判断主线与辅助，保留不确定项，完成综合叙述。

任何后层不得逆向伪造前层事实；Reasoner 可以综合，但不能改变盘面数据或补写缺失理论。
