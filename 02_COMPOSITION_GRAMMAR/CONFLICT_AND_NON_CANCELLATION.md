# Conflict and Non-cancellation

必须保留的边界：

```text
relation != path != outcome
opportunity != ability != result
earning != retention != capacity
income volatility != cash-flow velocity != loss
recognition != position != authority != money
stability != satisfaction
family support != family wealth source
family wealth != actual wealth transfer source
attraction != commitment
mechanism != pressure != instability != separation signal != event claim
absence != negative
NO_EVIDENCE != CONFLICTED
unknown != negative
```

- 支持与成本可以同时存在；不是互相抵消。
- 同宫化禄与化忌是两个不同 evidence group，可形成多维/冲突性表达，但不得合成净分。
- 不同主题下的信号不互相抵消；它们可能回答不同问题。
- 同一 evidence lineage 跨层重复只构成 resonance / re-activation，不增加独立票数。
- 真冲突是同一对象、范围、维度和语义槽中，相关证据产生不相容判断且旧知识未授权消解；来源争议、缺失、不同问题和成本并不自动等于真冲突。
