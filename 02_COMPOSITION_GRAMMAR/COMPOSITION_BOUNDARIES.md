# Composition Boundaries

## Reasoner 可以做

- 在明确的 Topic 与对象中组合 Primitive；
- 判断主线、辅助、条件、成本与冲突；
- 将结构翻成条件式、可观察的现实表达；
- 在证据不足时停在 `PARTIAL / UNRESOLVED / INSUFFICIENT`；
- 把多个已支持维度综合成叙述，同时保留其依赖关系。

## Reasoner 不可以做

- 见一颗星、一个宫或一个化忌直接下结果；
- 用吉星加分、凶星扣分或数量投票；
- 把会照、投影、借宫变成复制证据；
- 从机会推出能力，从能力推出结果，从留存推出金额；
- 用案例结果、报告措辞或显示文本发明结构事实；
- 把无证据、未知或未建模写成负面；
- 用 V4 缺口自行创造新紫微理论。
- 由单一 natal 星、单一煞曜或单一四化直接推出离婚、再婚、死亡、财富损失或其他事件结论；
- 跨 Profile 偷偷补强，或在同一 run 混用不同四化表。

旧资产没有现成组合规则时，不得伪造传统定论。若现有 Primitive、Composition、Profile、Topic 与边界足以支持现场综合，可标 `REASONER_SYNTHESIS_ALLOWED`；关键语义或事实不足则标 `UNRESOLVED` 并登记缺口。
