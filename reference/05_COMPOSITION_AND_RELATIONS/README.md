`COMPOSITE_FIRST` 表示先看合法组合与关系，不表示仓库必须列出所有组合。未预编码的组合可以 `UNRESOLVED / REASONER_SYNTHESIS_ALLOWED`；综合必须保留 source identity、局部事实和禁止推论。

Pattern 按正式方法使用 `REQUIRED / REINFORCING / BREAKING` 与 `COMPLETE / PARTIAL / BROKEN / INACTIVE`。两组枚举均为 `PROJECT_SCHEMA` 推理辅助，不构成封闭格局库。
