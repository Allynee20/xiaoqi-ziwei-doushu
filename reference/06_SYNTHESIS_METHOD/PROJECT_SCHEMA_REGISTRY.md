# Project Schema Registry

以下项目构造均标为 `PROJECT_SCHEMA`。它们用于分析一致性和审计，不声称是传统紫微斗数的原生、唯一或全流派共识分类。

| Schema | Role |
|---|---|
| `CAREER_LEVEL / CONTROL_LEVEL` | 区分个人执行、结果负责、资源协调与更高控制层，不从职位名直接推断 |
| `NATAL_RESOURCE_BASELINE` | 冻结本命资源基线 |
| `DECADE_RESOURCE_BAND` | 表示大运资源工作带，不等于财富保证 |
| `DECADE_DELTA` | 比较本命与前运的变化 |
| `FORMATION / STABILITY / SATISFACTION` | 分离关系形成、稳定和体验 |
| `RESOURCE_TRANSFER` | 区分资源存在与真实转移 |
| `SOFT_SIGNAL_STRENGTH` | `CLEAR_TENDENCY / HAS_SIGNAL / AUXILIARY_ONLY` |
| `PATTERN_COMPONENT_ROLE` | `REQUIRED / REINFORCING / BREAKING` |
| `PATTERN_COMPLETENESS` | `COMPLETE / PARTIAL / BROKEN / INACTIVE` |

完整定义仍以相应 Canonical/Protocol 文件为准。Schema 标签不得被写成传统定论，也不得自动产生现实结果。
