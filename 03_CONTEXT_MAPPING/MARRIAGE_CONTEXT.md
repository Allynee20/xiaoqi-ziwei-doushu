# Marriage Context

Canonical claim ladder: `PROJECT_SCHEMAS/MARRIAGE_EPISTEMIC_SCHEMA.md` (`PROJECT_EPISTEMIC_SCHEMA`).

婚姻/关系必须保持单盘倾向与双方事实的边界。未知现实状态时不得预设单身、恋爱、已婚、离异或再婚。

## 主线角色

- 夫妻宫：一对一承诺、协商、共同生活/项目责任。
- 命/福德：本人的关系需要、边界、承受与满足。
- 财帛/田宅：共同资源、支出、居住与家庭基础。
- 迁移/交友/官禄/兄弟：认识渠道、外部平台、工作往来与协作环境；仅在有明确对象时使用。

## 必须分开的维度

伴侣指涉倾向、关系内吸引、外部注意条件、冲突机制、稳定/连续性、情感满足不能合成一个“婚姻好坏”。吸引 != 进入关系 != 稳定；稳定 != 满足；外部注意 != 出轨事实。

## 关系阶段

认识、升温/确认、亲密/同居、见家长/谈婚、登记/婚礼、冲突/疏离、分手/离婚分别判断。原局给题材，阶段层给舞台，流年只在现实对象与条件成立时放大议题。

严格夫妻太极映射已由 V1 使用，但跨一层以上转宫及其通用可靠性为 `PARTIAL`；默认只转一层，并同时保留本命物理宫义。

单一 natal 星、单一煞曜或单一四化只能支持 mechanism/pressure 候选，不能直接升级为 separation, divorce, remarriage or event claim。吸引力不自动升级为承诺；稳定性与满意度分别判断。
