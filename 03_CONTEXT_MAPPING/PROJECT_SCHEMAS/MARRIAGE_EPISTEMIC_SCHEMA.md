# Marriage Epistemic Project Schema

Status: `ACCEPTED_PROJECT_SCHEMA`  
Origin label: `PROJECT_EPISTEMIC_SCHEMA`

The ladder is epistemic: it controls how strong a claim is allowed to become. It is not a deterministic event algorithm.

| Level | Meaning | Allowed output |
|---|---|---|
| `MECHANISM` | A natal interaction tendency or relationship mechanism | Conditional mechanism description |
| `PRESSURE` | Friction, burden or constraint is supported | Pressure/cost statement, not outcome |
| `INSTABILITY` | Multiple relevant facts support discontinuity or variability | Instability tendency, not separation |
| `SEPARATION_SIGNAL` | Profile-valid multi-layer evidence supports separation pressure | Signal only; reality and trigger remain required |
| `EVENT_CLAIM` | A selected time profile meets its explicit necessary conditions | Conditional, uncertainty-bearing event claim |
| `REPEATED_RELATIONSHIP_CLAIM` | Independent profile-specific evidence exists | Never inferred by accumulating separation signals |

Core prohibitions:

- one natal star, one malefic or one transform cannot directly produce divorce, remarriage or another event claim;
- stability and satisfaction are separate dimensions;
- attraction and commitment are separate dimensions;
- no automatic `ATTRACTION → COMMITMENT` conversion;
- traditional single-star marriage aphorisms are `SCHOOL_SPECIFIC_RAW_TRADITION`, not Core Grammar;
- mechanism, pressure, instability and event are not interchangeable.

The default profile leaves event claims conservative and conditional. A missing dynamic grammar must produce `KNOWLEDGE_GAP`, not an upgraded prediction.
