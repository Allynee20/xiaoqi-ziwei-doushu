# Career Context

事业层在 V3 主要完成维度分离，具体语义规则仍多为 `PARTIAL/UNRESOLVED`。Reasoner 应区分：

| 维度 | 主线接口 | 不可替代成 |
|---|---|---|
| 工作功能/贡献方式 | 命身 + 官禄的直接工作功能信号 | 实际表现、职业、位置、权力、结果 |
| 组织/平台适配 | 官禄 + 明确平台对象；迁移/交友作环境条件 | 平台入口、雇佣事实、稳定、满意 |
| 机会/资源入口 | 迁移、交友、父母/制度、官禄的明确入口 | 能力、适配、晋升、结果 |
| 能力倾向 | 命身、主星功能与独立能力证据 | 机会、认可、实际绩效 |
| 专业认可/可见度 | 官禄、昌曲/科与作品、验收、反馈 | 位置、权力、钱、成就 |
| 正式位置 | 独立的位置/席位结构 | 工作方式、具体头衔、权力、晋升 |
| 权责 | 官禄、权及明确决策/责任对象 | 正式位置、名声、金钱、实际权力结果 |
| 稳定/变化 | 直接连续性/变化证据 | 发展、满意、成功/失败、具体离职 |

现实工作链可用于检验：入口 -> 授权 -> 角色 -> 资源 -> 交付 -> 验收 -> 结算/复用。只有外部接触而无承接与结算，不等于机会已落地。
