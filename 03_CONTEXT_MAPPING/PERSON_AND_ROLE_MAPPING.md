# Person and Role Mapping

一个宫位不天然等于某个外部人物。每次分析先显式锚定 `subjectRef`、关系对象和现实载体。

| 角色 | 优先映射 | 复核 / 边界 |
|---|---|---|
| 本人 | 命、身；具体主题宫 | 命身不覆盖主题对象 |
| 伴侣/一对一对象 | 夫妻；命/福、财/田复核互动与共同基础 | 无对象时只读本人模式；不猜对方事实 |
| 父母/长辈 | 默认 `PARENT_PAIR_CONTEXT`；父母宫看关系与原生家庭语境 | `NO_SAFE_GENERAL_FATHER_MOTHER_SPLIT`；太阳/太阴仅为传统父系/母系关联信号，`DESCRIPTIVE_ONLY`、`NOT_OBJECT_ASSIGNMENT` |
| 子女/后辈 | 子女 | 无子女时可读作品/项目/培养责任，但不得偷换 |
| 老板/上级 | 官禄、父母/制度接口 | 交友可表示协作网络；不得单宫固定化 |
| 单位/平台 | 官禄；迁移看外部平台，父母看制度 | 平台适配 != 平台入口 |
| 团队/客户/供应商 | 交友/仆役；迁移/官禄复核场景与职责 | 不简化为人缘或贵人小人 |
| 家庭 | 田宅、父母、夫妻、子女依具体对象分工 | 不把家庭支持等同财富来源 |
| 外部环境 | 迁移 | 不直接等于异地、迁居或成功 |

若角色可能有多个合法映射，Reasoner 必须列出主映射、辅助映射与未决条件，而不是任选一个。

禁止预测父母健康、寿命、谁先亡，禁止用太阳/太阴把全部 evidence 强制分配给父或母。Family Support 的对象层级使用 `PROJECT_SCHEMAS/FAMILY_SUPPORT_L1_L5_SCHEMA.md`。
