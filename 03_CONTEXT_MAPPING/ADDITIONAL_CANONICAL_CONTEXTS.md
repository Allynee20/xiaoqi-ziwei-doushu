# Additional Canonical Context Mappings

Status: `PARTIAL`, with accepted boundaries. This file consolidates high-value local P1 assets without pretending to be complete.

## Parents / family origin

- Parent palace: parent-pair relationship, childhood environment, elder/institution/education interfaces.
- Property and Fortune may describe family base or inherited environment only when the question and evidence object match.
- Family support, family wealth and actual transfer remain separate L1–L5 objects.
- Empty Parent palace uses the same Core borrow physics as every other palace; Topic changes interpretation only.

## Property / home / asset base

- Covers residence, fixed base, operating base, storage, property and family asset channels.
- `祖业`, `自置`, `退祖`, and `先破后有` remain distinct source/profile branches.
- Property evidence is not automatically wealth retention, house ownership or family transfer.
- Empty Property palace retains all target-local facts and uses accepted Core borrow grammar.

## Friends / team / clients

- Separate friends, coworkers, partners, clients, suppliers, team resources and interpersonal costs by the question's role object.
- A support/resource route does not become a “benefactor” or result without an explicit role and delivery path.

## Migration / external environment

- May describe external platforms, public/client settings, mobility, travel, relocation context and opportunity entry.
- Entry, acceptance and settlement are separate stages; external opportunity does not prove adaptation or result.

## Career

Keep these dimensions separate: work role, environment/platform fit, independent vs organizational mode, professional ability, execution, management/responsibility, recognition, position, authority, pay, stability/change, pressure source, supervisor/team interface, external platform and career–wealth coupling.

```text
recognition != position != authority != pay
platform entry != platform fit != result
ability != execution != management burden
```

## Dynamic context

Decade/annual facts may be used only through the selected profile. Calculable fields without profile grammar remain `PARTIAL` or produce `KNOWLEDGE_GAP`.
