# Other Active Primitives

## 时间层

- 本命：长期、低频、反复出现的题材候选。
- 大限：把既有结构放入约十年舞台；不创造新线路或结局。
- 流年：选择年度优先核验的对象/流程；不凭空创造事件。
- 流月/流日：只对已成立的题材、舞台和现实对象缩时。
- 同一物理路线跨层重复：一条结构证据，多层强度/应期，不是多票。

## 结构身份

- `physicalPalace`：证据的真实物理来源。
- `stage3Target` / 当前主题目标：Reasoner 正在读取的接口，不改写来源。
- `projectionKind`：`LOCAL`、`SANHE`、`OPPOSITE`、`BORROWED_VIEW`。
- `evidenceGroupId` / `sourceEvidenceId`：去重和追溯同一物理事实。
- `subjectRef` / `relationTargetRef` / `externalTargetRef`：人物与关系对象必须显式锚定；不可猜测。
