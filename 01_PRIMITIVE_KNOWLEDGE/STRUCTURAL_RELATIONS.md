# Structural Relations

| 关系 | 结构含义 | 推理角色 | 边界 |
|---|---|---|---|
| 本宫 / LOCAL | 星曜实际所在物理宫及其直接对象接口 | 主证候选、局部基底 | 本宫事实仍需组合，不等于结果 |
| 对宫 / OPPOSITE | 六条相对轴的另一端，提供外部界面、牵制或互见 | 背景、对照、牵制、条件 | 普通对宫会照不等于飞忌冲；不是自动加一票 |
| 三方 / SANHE | 与主题宫形成三合拓扑的两个物理宫 | 资源、场景、支持或修饰 | 投影不改变物理来源；不可链式再投影 |
| 三方四正 | 本宫、对宫、两组三合的结构阅读框架 | 把主语、外部、资源、责任放入同一结构 | 不能以数量多数决定结论 |
| 会照 | 相关宫位的结构性参与 | 支持、压力、条件或修饰 | 必须说明提供什么，不等于同宫或主证 |
| 夹宫 | 相邻结构对目标的环境性夹持/辅助 | 环境推动或限制 | 与同宫/会照力度不同；稳定通用语义仍 `PARTIAL` |
| 借宫 | 空/待定主调目标在满足条件时读取物理对宫主调 | `BORROWED_VIEW` | 不是搬迁，不产生新星、新四化或新证据；不得借资源/显示文本 |
| 命身关系 | 命宫偏基础反应；身宫作为后天参与/强调元数据 | 行为参与度与主题强调 | 身宫不单独生成结论 |
| 固定飞化有向边 | 发射宫 -> 宫干 -> 化星 -> 星曜所在物理宫 -> 对宫 | 主题关系与作用方向 | 生年四化与宫干飞化分层；最多有限追踪，避免无限串线 |

六条对宫轴：命迁（身份/外部）、兄友（同辈/团队）、夫官（一对一承诺/现实责任）、子田（产出/照护/家庭基础）、财福（资源/满足/承受）、疾父（日常负荷/制度支持）。轴义是阅读提示，不是固定结果。
