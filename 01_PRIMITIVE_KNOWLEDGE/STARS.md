# Stars

本文件只保存旧资产已经使用的基础语义候选。星曜不是人的固定本质，不能脱离宫位、同宫/对宫/三方、四化、状态与问题对象直接下结论。

## 十四主星

| 星曜 | 核心语义与作用方式 | 典型倾向 | 边界 / 不能直接推出 |
|---|---|---|---|
| 紫微 | 安住局面、承担、主心骨、希望有分量 | 顺时组织与担当；卡时硬撑、不愿示弱 | 不等于领导、富贵；须看左右、资源与执行出口 |
| 天机 | 思考、变化、替代方案 | 快速找办法；压力下多想多改 | 不等于一定聪明、漂泊 |
| 太阳 | 承担、照顾、站到前面 | 主动支撑；卡时过度证明 | 不等于一定外向；昼夜旺陷影响仍待完整迁移 |
| 武曲 | 结果、数字、效率、兑现 | 重落地和结算；卡时硬、急于算清 | 不等于爱钱或特定金融职业 |
| 天同 | 舒适、善意、相处感 | 缓和、亲和；卡时拖延避冲突 | 不等于懒散 |
| 廉贞 | 边界、规则、关系位置 | 重秩序与定位；卡时较真拧巴 | 不等于桃花问题、官非 |
| 天府 | 收纳、守成、资源安排 | 能守能收；卡时保守、怕失控 | 不等于富有 |
| 太阴 | 观察、安全感、私下品质 | 细致与比较；卡时闷住反复 | 不等于柔弱或女性化 |
| 贪狼 | 接触、体验、资源与人际扩展 | 好奇、多入口；卡时欲望/选择分散 | 不等于贪玩或桃花多 |
| 巨门 | 追问、辨别、表达异议 | 会拆分与质疑；卡时怀疑、嘴硬或憋话 | 不等于必有口舌是非 |
| 天相 | 公平、流程、协调 | 成全与收尾；卡时夹在中间 | 不等于秘书/行政职业 |
| 天梁 | 原则、保护、长期后果 | 承担、看长线；卡时说教或过度负责 | 不等于清高、晚婚 |
| 七杀 | 决断、应对挑战、清晰输赢 | 敢上、行动快；卡时急硬独扛 | 不等于孤克、离婚 |
| 破军 | 拆旧、重做、重组 | 敢于重启；卡时反复推翻 | 不等于一生大破大立 |

## 已迁移的辅星、煞星与杂曜

| 星群 | 基础作用 | 边界 |
|---|---|---|
| 左辅、右弼 | 分工、补位、持续协作；所在主题更易接入人力支持 | 同宫、会照、夹辅不同；不一律称贵人 |
| 文昌、文曲 | 说明、记录、方案、表达、审美、文书与验收链 | 不直接断学历、文凭、名声 |
| 天魁、天钺 | 入口、提点、资格门槛、被看见 | 不等于终身有靠山 |
| 禄存 | 可守、可用资源与稳定渠道候选 | 不等于发财 |
| 天马 | 流动、移动场景、资源随行动展开 | 不等于出国；与禄存合看也只表示“跑动后有收获”的候选 |
| 擎羊、陀罗 | 羊偏快直敢顶；陀偏慢忍卡住 | 只作摩擦/节奏/安全修饰，不断伤灾 |
| 火星、铃星 | 火偏突然点燃；铃偏紧绷警觉 | 不可单断事故、疾病 |
| 地空、地劫 | 跳出旧框架、非常规、落空感或资源不踏实 | 不可直接断破财、孤苦 |
| 天哭、天虚 | 对落差、遗憾、不被理解较敏感 | 只写情绪质感，不作心理诊断 |
| 孤辰、寡宿 | 需要独立空间、倾向独自想透 | 不等于孤独终老或婚姻差 |
| 解神 | 拆题、补救与修复出口 | 不取代主星 |
| 天才 | 学习快、希望凭本事被认出 | 不取代主星或直接断成就 |
| 天贵、天寿、恩光、天德、月德 | 缓冲、善意环境的细节修饰 | 不作身份、福寿或事件断语 |

其余实际盘面杂曜的稳定 Primitive Meaning：`UNRESOLVED`。存在星名不等于 V4 已有可用语义。
